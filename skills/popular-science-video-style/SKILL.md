# 科普短视频默认风格

基于 Fable 5 科普视频 v3 定稿风格。以后做科普/技术热点视频默认用这套。

## 画布

- 竖屏 1080×1920
- 总时长 45-60s
- 深色科技风背景
- 三层背景动效：光球(orbs) + 粒子(particles) + 扫描线(scanline)
- 配色：蓝紫渐变主色，霓虹青(#00f0ff)强调

## 字体

- 标题：≥72px，ZCOOL KuaiLe 或系统字体
- 字幕：**ZCOOL KuaiLe 64px**
- 字幕位置：MarginUser 280（底部偏上，不贴底边）
- 字幕对齐：Alignment=2（底部居中）
- **禁止加shadow/背景框**——白字直接叠在画面上

## TTS

- 音色：zh-CN-YunxiNeural（男，青年，活泼阳光）
- 语速：+10%
- 长文本必须用 --file，不能用 --text（>100字会静默失败）
- 按场景分段生成，用 adelay 对齐

## 场景结构

典型结构（按内容调整）：
1. 标题卡（4s）：大标题 + 副标题
2. 发布/背景信息（6-8s）
3. 核心能力/亮点（8s × 2-3个）
4. 价格/对比（6-8s，可选）
5. 槽点/争议（6s，可选）
6. 结尾引导（4s）

需要展示软件界面时，加载 `macos-claude-ui` skill 做虚拟录屏场景。

## 字幕规格

- 每条 ≤12 字
- 单行不换行
- 时间用 Whisper 词级对齐（faster-whisper medium）
- 禁止按字数均分时间
- ASS 时间基匹配目标视频时长（注意 1.2x 加速前后）

## ASS 模板

```
Style: Default,ZCOOL KuaiLe,64,&H00FFFFFF,&H000000FF,&H00000000,&HB0000000,0,0,0,0,100,100,0,0,3,0,0,2,60,60,280,1
```

关键参数：
- Fontsize=64
- Outline=3（描边，不是背景框）
- Shadow=0（无阴影）
- Alignment=2, MarginV=280

## 动画规则

- 入场：0.4-0.7s, ease-out
- 同屏最多 2 层动画
- 禁止弹跳/抖动
- 标题 shimmer 流光 8s 循环，同色系亮 2-3 档
- 呼吸感：动画间留 0.3-0.8s 空白

## 管线

1. HTML 场景 → Playwright 截帧 (fps=15, 1080×1920)
2. FFmpeg 编码每场景 → concat
3. 1.2x 加速（setpts + atempo）
4. **ASS 字幕烧入**（fontsdir=~/.fonts/）← 在加速之后，因为ASS时间戳是1.2x视频时间基
5. 输出 .mp4

注意：先加速再烧字幕。如果先烧字幕再加速，字幕会被压缩导致错位。

## 注意事项

- fontsdir=~/.fonts（ZCOOL KuaiLe 在此目录）
- 定稿后不改动产物。"以后默认用这个"=存配置，不是改当前成品
- 版本轮转：做完新版→上一版留/tmp备份→更早的全删
- 清理中间文件前确认新版本已验证通过，否则需要从头重建
