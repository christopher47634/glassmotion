# 逐场景从零设计工作流（2026-06-06 起生效）

## 背景：为什么废弃批量管线

L03/L04 逐课定制了场景内容，效果好。但 L05-L10 用"模板+替换元数据"批量产出：
- 只改 lesson 编号和模块标签
- 场景里的工作流演示、提示词卡片、避坑面板从 L04 原封搬
- 结果 L05-L10 全是 L04 的内容换了层皮

**根因**：
1. 混淆"框架层"（CSS/GSAP/字幕系统，可复用）和"内容层"（场景展示什么，必须逐课设计）
2. 验证只查形式（方块字、布局），没查内容是否匹配分镜表
3. 贪快——以为换个模板就能批量出

## 新工序：每个场景走 4 步，不许跳

```
分镜表第 N 行
    │
    ▼
Step ① 设计规格 ──→ 发 User 确认
    │
    ▼
Step ② 从零写 HTML（只复用框架层，内容层全新设计）
    │
    ▼
Step ③ 截帧验证：方块字 + 内容匹配分镜表关键词
    │
    ▼
Step ④ 通过 → 做下一场；不通过 → 重做这一场
```

## Step ① 设计规格模板

```markdown
### 场景 N：[分镜表原文摘要]

- **布局**：[居中/左文右图/分屏/卡片翻转/...]
- **真实素材**：[具体 PNG/图标描述，不用通用 SVG]
- **主题色**：[hex 值，从分镜表语义推导]
- **GSAP 动画**：
  - 入场：[ease/duration/delay]
  - 退场：[ease/duration]
  - stagger：[间隔/方向]
- **字幕**：[该场景的字幕文本]
- **时间区间**：[start ~ end，从 VTT 推算]
```

## Step ③ 验证清单

| 检查项 | 标准 | 不通过处理 |
|--------|------|-----------|
| 方块字符 | 0 个 | 检查字体子集是否包含该字符 |
| 分镜表关键词 | 截图中出现 ≥80% | 场景内容写错了，重做 |
| 布局匹配 | 截图布局 = 设计规格 | 调整 HTML |
| 动画到位 | 关键帧展示动画中间态 | 检查 GSAP timeline |
| 字幕可见 | 字幕区域完整显示 | 检查 padding-bottom |

## 哪些可以复用，哪些必须从零

| 层 | 能否跨课复用 | 举例 |
|----|-------------|------|
| CSS reset / 变量 | ✅ 可以 | `:root` 色板、字体声明 |
| GSAP 工具函数 | ✅ 可以 | `staggerIn()`, `slideUp()` |
| 字幕系统 | ✅ 可以 | `window.seekTo()` |
| HUD 外框 | ✅ 可以 | 课程标题栏、进度条 |
| 场景内容 | ❌ 必须从零 | 卡片文字、演示面板、图标选择 |
| 布局结构 | ❌ 必须按分镜表 | 分屏 vs 居中 vs 卡片翻转 |
| 配色 | ❌ 必须按语义 | 龙虾=红，AI=蓝，不是固定色板 |

## 子代理使用规则

- 主代理逐场景做
- 如确需子代理：必须传入完整的 Step ① 设计规格
- 子代理产出必须经过 Step ③ 验证
- 禁止让子代理自己从分镜表推导场景内容
