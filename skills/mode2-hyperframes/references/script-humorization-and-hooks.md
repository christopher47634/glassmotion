# 脚本幽默化改写 + Hook策略 + 可爱化动效

> 当脚本受众是学生（小学~高中），需要将正式讲解风格转为轻松口语风格时使用。

---

## 1. 语气风格转换规则

### 禁用词/表达（硬红线）
- "必须"、"一定"、"记住"、"红线"、"大陆"、"老师一眼看穿"
- 恐吓式表述、说教式祈使句
- 过于正式的书面语

### 替换策略
| 原表达 | 替换为 |
|--------|--------|
| "你必须这样做" | "你要是这样做的话……（效果描述）" |
| "一定不能" | "咱就别……了，原因你懂的" |
| "记住这个技巧" | "这个技巧你记一下，后面用得到" |
| 直接命令 | 反问 + 结果描述 |
| 严肃警告 | 轻吐槽 + 自嘲 |

### 目标语气
- **B站UP主聊天感**：像学长学姐边走边聊
- **偶尔自嘲**：比如"我当年就犯过这错"
- **轻吐槽**：吐槽现象，不吐槽人
- **生活化比喻**：把技术操作比作日常场景
- **信息量不打折**：轻松≠偷懒，该说的全说到

### 句式偏好
```
反问句（首选）: "你有没有那种……的感觉？"
自嘲句: "我当年直接复制粘贴，结果……"
类比句: "就像你点外卖选套餐一样"
假设句: "你要是……的话，效果就……"
条件句: "遇到这种情况，咱就……"
```

## 2. Hook策略（片尾附加）

### 什么是Hook
每节课末尾附加1-2句简短台词，将本课技能延伸到更广泛的大学/学生生活场景。
Hook是附加内容，**不修改原有分镜结构**。

### Hook设计原则
- **场景延伸**：把本课教的技能映射到用户没想到但相关的场景
- **一句话点到**：不需要展开，留下印象即可
- **强调"身边能用到的AI"**：不用额外工具、不用魔法上网
- **语气轻松**：像顺嘴提一句，不像新增教学内容

### Hook位置
在每课脚本的课程定位（`【定位】`）之后、正文之前添加：
```
【Hook · 片尾附加】
结尾可以说：
"XX技能不光能用来……，你还可以拿它……。"
```

### Hook示例（第1-2课 PPT+报告）
```
结尾可以说：
"今天学的不光能帮你搞定课业PPT，你还可以拿它做社团招新海报、比赛宣传图。
工具都一样，思路换一下就行。"
```

## 3. 动效Tips — 可爱化方向

> 适用于面向年轻学生群体的视频。与 `animation-inspiration.md` 中的"高级感/克制型"风格互补，
> 不同受众用不同风格。选择依据：受众年龄和内容调性。

### 什么时候用可爱化
- 受众：小学生、初中生、高中生、大学生（轻松教育类）
- 内容调性：轻松、有趣、不让人生畏
- 品牌调性：亲切、活泼、有活力

### 什么时候用高级感（克制型）
- 受众：职场人士、专业人士
- 内容调性：严肃、权威、可信
- 品牌调性：专业、稳重

### 可爱化设计规范

#### 视觉元素
| 元素 | 参数 |
|------|------|
| 圆角 | ≥ 16px（卡片、按钮、容器） |
| 阴影 | 柔和扩散：`0 4px 20px rgba(0,0,0,0.08)` |
| 色彩 | 明亮但不刺眼，饱和度中等偏高 |
| 字体 | 圆润/手写风格，避免太正式的衬线体 |

#### 缓动选择（可爱化专用）
| 场景 | 缓动 | 效果 |
|------|------|------|
| 元素入场 | back.out(1.7) | 微弹入场，活泼 |
| 强调/弹出 | elastic.out(1, 0.5) | 弹簧感，俏皮 |
| 数字滚动 | power2.out | 流畅自然 |
| 背景微动 | sine.inOut | 柔和呼吸 |
| 进度条 | power3.inOut | 丝滑推进 |

> 注意：这些缓动在"高级感"风格中被标记为"禁止"。
> 风格选择取决于受众，不是绝对规则。

#### 动画模式
```
可爱入场:   opacity 0→1, scale 0.8→1.05→1, duration 0.6, ease: back.out(1.7)
弹性强调:   scale 1→1.2→1, duration 0.4, ease: elastic.out(1, 0.5)
打字机效果: 逐字出现 + 每字微弹（scale 1→1.05→1）
对话气泡:   scale 0→1, opacity 0→1, ease: back.out(2), 轻微旋转摆动
图标放大:   hover/强调时 scale 1→1.2, duration 0.3, ease: power2.out
装饰微动画: 星星/心形 缓慢旋转或脉动，sine.inOut, yoyo: true, repeat: -1
```

#### 装饰元素（可选）
- Q版人物/动物角落装饰（淡入淡出循环）
- emoji飘入（用于数字展示、成就达成）
- 进度条伴随机关枪式音效提示（视觉反馈）
- 对话气泡式旁白（代替传统字幕条）

#### 页面切换
- 推拉 + 淡入淡出组合
- 避免硬切（太突兀）
- 可加轻微弹性（scale 0.98→1）

### 逐课动效Tips模板

每课脚本中在Hook之后添加：
```
【动效 Tips · 可爱化】
- [具体场景]：[具体动画建议，如"圆角卡片+弹性入场+emoji点缀"]
- [另一个场景]：[建议]
- 圆角 ≥ 16px，缓动用 back.out(1.7)，icon 放大 1.2 倍（强调时）
- 装饰：[根据课程内容选择合适的装饰元素]
```

## 4. 并行重写执行模式

### 场景
将15+节课的台词从正式风格重写为口语化风格。

### 分解策略
- 每波3节课，5波并行
- 每波用 `delegate_task` 派给独立子agent
- 子agent用 `patch` 工具逐段替换台词
- 同时更新分镜表中的台词引用和bumper文案

### 注意事项
- `delegate_task` 有600秒超时限制，3课/波是安全上限
- API限流（429）可能导致子agent提前终止，需事后验证文件内容
- 改写后必须抽样读取验证，不能只信任子agent的自报

### 子agent prompt要点
1. 明确告知文件路径和目标段落范围
2. 给出禁用词列表和替换策略
3. 要求保留时间码、分镜编号、画面描述不变
4. 只改口播台词、分镜表台词引用、bumper文案
5. 给出示例改写（before/after）让子agent对齐风格

## 5. 台词修改铁律

### User 的明确要求
1. **已定稿的台词不要动。** 用户说"第一集先别碰稿子内容了"时，该集台词完全冻结。
2. **"大陆"→"身边能用到的"**：替换标签化表述，但只做精确替换，不改其他措辞。
3. **逐字稿恢复**：如果用户说"后面的全部恢复最开始那版"，必须恢复原版，只保留已确认的替换（如"大陆"→"身边能用到的"）。
4. **不要改细节**："恭喜你考上大学啊"这类表达不要改成别的，保持原味。

### 替换时的精确操作
- 用 `patch` 工具的 `old_string` 精确匹配要替换的词
- 不要用全局替换，避免误伤其他内容
- 替换后用 `read_file` 验证上下文没被破坏

## 6. 标题动效规范

### 流光效果（推荐）
标题文字用 CSS `background-clip: text` + 渐变动画实现流光效果：

```css
.title {
  background: linear-gradient(90deg, #1A4DF0, #15C9B0, #1A4DF0);
  background-size: 200% 100%;
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  animation: shimmer 3s ease-in-out infinite;
}
@keyframes shimmer {
  0% { background-position: 200% 0; }
  100% { background-position: -200% 0; }
}
```

### ❌ 禁止的标题动效
- **抖动/抽搐**：transform: rotate/scale 随机抖动 → User 说"标题在抽搐"
- **弹跳**：elastic/back 缓动用在标题上 → 看起来不稳定
- **闪烁**：opacity 快速变化 → 眼睛不舒服

### 原则
标题是视觉锚点，应该**稳定、优雅、有质感**。流光、渐变色、微妙的光晕是可以的。任何让标题"动来动去"的效果都需要极其谨慎。
